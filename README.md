# Healthcare Insurance Project

## Project Description
This project is an automation testing framework developed using Selenium WebDriver, Java, TestNG, and Maven for Healthcare Insurance Application functionalities.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven

## Test Scenarios Covered
1. Login Page UI Validation
2. Login Functionality Validation
3. User Registration Validation
4. Policy Management Validation
5. Claims Processing Validation
6. Premium Payment Validation
7. Customer Support Validation
8. FAQ Validation
9. Bug Scenario Validation

## Features
- Data Driven Testing using DataProvider
- Assertions Validation
- WebDriverWait Implementation
- Reusable BaseTest Class
- TestNG XML Execution
